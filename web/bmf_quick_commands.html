🔧 Fix Discord Bot

To enable automatic Discord replies:

  1. Go to Discord Developer Portal
  2. Select AIPA application
  3. Go to Bot → Privileged Gateway Intents
  4. Enable "Message Content Intent"
  5. Save changes
  6. Run: python discord_bot_bmf.py
