# Web Interfaces

## Files
- `bmf_web_logger.html` - Browser-based BMF work logging interface
- `bmf_quick_commands.html` - Quick command interface (if exists)

## Usage
1. Open `bmf_web_logger.html` in your browser
2. Update the Discord webhook URL with your actual webhook from `config/CREDENTIALS.md`
3. Enter work description and submit

## Features
- Simple web form for BMF work entries
- Direct Discord webhook integration
- Real-time feedback
- No server required (client-side only)

## Setup
⚠️ Before using, replace `YOUR_DISCORD_WEBHOOK_URL_HERE` with your actual webhook URL
