## Using a Local LLM (LM Studio)

This project can leverage a local Large Language Model running via LM Studio. This allows for offline, private generation of content for tools like the spec generator.

### 1. Prerequisites

-   **LM Studio**: Download and install from [https://lmstudio.ai/](https://lmstudio.ai/).
-   **Run the Server**: Inside LM Studio, navigate to the "Server" tab (server icon on the left) and click "Start Server". Ensure it's running on the default port `1234`.

### 2. Configuration

The local LLM adapter (`tools/lms_adapter.py`) is configured via environment variables.

-   `LMS_HOST`: The host and port of the LM Studio server. Defaults to `127.0.0.1:1234`.
-   `LMS_API_KEY`: A dummy API key. LM Studio doesn't require one by default, but the header is sent for compatibility.

You can set these in your shell before running scripts:
```powershell
# Example for PowerShell
$env:LMS_HOST="127.0.0.1:5000"
```

### 3. Generating Specs with the Local LLM

The `speckit_generate.py` tool can use your local model to generate the body of a technical specification.

Use the `--use-local-llm` flag:
```powershell
python tools/speckit_generate.py --feature "My New Awesome Feature" --use-local-llm
```
This will create a new spec file in the `docs/` directory with the content generated by your local model.

### 4. Using the Adapter in Scripts

You can import and use the `generate` function from the adapter in any Python script.

**Example (`tools/example_local_llm.py`):**
```python
# Add project root to path to allow imports
import sys
import os
sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(__file__), '..')))

from tools.lms_adapter import generate

# Simple non-streaming call
print("--- Generating a simple response ---")
response = generate("What are the core principles of good software design?")
print(response)

# Streaming call
print("\n--- Streaming a story ---")
for chunk in generate("Tell me a short story about a curious robot.", stream=True):
    print(chunk, end='', flush=True)
print()
```
