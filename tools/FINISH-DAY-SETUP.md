# Finish Day Agent - Universal Git Tool

## What It Does

A Claude-powered end-of-day Git tool that works in **ANY project**:
- ✅ Analyzes your changes intelligently with Claude AI
- ✅ Generates professional commit messages
- ✅ Stages, commits, and pushes automatically
- ✅ Works in any Git repository
- ✅ Provides daily commit summaries

---

## Quick Setup (5 minutes)

### Step 1: Install Python Package

```bash
pip install anthropic
```

### Step 2: Set API Key

**Windows (PowerShell)**:
```powershell
$env:ANTHROPIC_API_KEY = "your-api-key-here"

# Make it permanent:
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_API_KEY', 'your-key', 'User')
```

**Linux/Mac**:
```bash
export ANTHROPIC_API_KEY="your-api-key-here"

# Make it permanent (add to ~/.bashrc or ~/.zshrc):
echo 'export ANTHROPIC_API_KEY="your-api-key"' >> ~/.bashrc
```

### Step 3: Make Globally Accessible

**Option A: Add to PATH (Recommended)**

```bash
# Windows: Copy to somewhere in your PATH
copy finish-day.py C:\Users\woody\bin\finish-day.py

# Linux/Mac: Copy to /usr/local/bin
sudo cp finish-day.py /usr/local/bin/finish-day
sudo chmod +x /usr/local/bin/finish-day
```

**Option B: Create Alias**

```bash
# Add to ~/.bashrc or ~/.zshrc:
alias finish-day="python /path/to/finish-day.py"

# Or Windows (PowerShell profile):
function finish-day { python C:\path\to\finish-day.py $args }
```

**Option C: Create Batch File (Windows)**

Create `finish-day.bat`:
```batch
@echo off
python C:\Users\woody\Documents\AI\AIPA\tools\finish-day.py %*
```

Copy to `C:\Windows\` or add its folder to PATH.

## Usage

### Basic Usage (Interactive)

```bash
cd /your/project
finish-day
```

Or:
```bash
python finish-day.py
```

**What happens**:
1. Analyzes all changes
2. Claude generates commit message
3. Shows you the message
4. Asks for confirmation
5. Commits and pushes

### Auto Mode (No Confirmation)

```bash
finish-day --auto
```

Perfect for end-of-day routine:
- Analyzes changes
- Generates message with Claude
- Commits and pushes automatically
- No questions asked

### Analyze Mode (Preview Only)

```bash
finish-day --analyze
```

Shows what would be committed without actually committing.

### Daily Summary

```bash
finish-day --summary
```

Shows all commits made today.

## Advanced Usage

### Custom Workflow

Create your end-of-day script:

**`eod.sh` (Linux/Mac)**:
```bash
#!/bin/bash
echo "🌙 End of Day Routine Starting..."

# Run tests
npm test

# If tests pass, commit
if [ $? -eq 0 ]; then
    finish-day --auto
    echo "✅ All done! Have a great evening!"
else
    echo "❌ Tests failed. Fix before committing."
fi
```

**`eod.bat` (Windows)**:
```batch
@echo off
echo 🌙 End of Day Routine Starting...

REM Run tests
npm test

REM If tests pass, commit
if %errorlevel% == 0 (
    python finish-day.py --auto
    echo ✅ All done! Have a great evening!
) else (
    echo ❌ Tests failed. Fix before committing.
)
```

### Scheduled Auto-Commit

**Windows Task Scheduler**:
1. Open Task Scheduler
2. Create Basic Task
3. Trigger: Daily at 6 PM
4. Action: Start a program
5. Program: `python`
6. Arguments: `C:\path\to\finish-day.py --auto`
7. Start in: Your project directory

**Linux/Mac Cron**:
```bash
# Add to crontab (crontab -e):
0 18 * * * cd /path/to/project && python /path/to/finish-day.py --auto
```

## Configuration

### Environment Variables

```bash
# Required
ANTHROPIC_API_KEY=your-claude-api-key

# Optional (defaults work fine)
FINISH_DAY_BRANCH=main          # Default branch to push to
FINISH_DAY_AUTO_PULL=true       # Auto-pull before push
FINISH_DAY_VERBOSE=false        # Extra logging
```

### Project-Specific Config

Create `.finish-day.json` in your project root:

```json
{
  "auto_stage": true,
  "auto_push": true,
  "default_branch": "main",
  "ignore_patterns": [
    "*.log",
    "temp/*"
  ],
  "commit_prefix": "auto: ",
  "require_tests": false
}
```

## How It Works

### 1. Change Detection
- Scans Git status (staged, unstaged, untracked)
- Gets diff statistics
- Captures code changes

### 2. Claude Analysis
- Sends changes to Claude
- Claude analyzes:
  - What was changed
  - Why (inferred from code)
  - Best commit type (feat/fix/docs/etc)
- Generates professional commit message

### 3. Git Workflow
- Stages all changes (`git add -A`)
- Creates commit with Claude's message
- Pulls latest changes (rebase)
- Pushes to remote

### 4. Verification
- Shows commit summary
- Lists recent commits
- Confirms sync status

## Commit Message Format

Claude generates commits following **Conventional Commits**:

```
type(scope): brief description

- Detailed point 1
- Detailed point 2
- Detailed point 3

🤖 Generated by Finish Day Agent
📅 2025-11-01 18:30:00
```

**Types**:
- `feat`: New feature
- `fix`: Bug fix
- `docs`: Documentation
- `style`: Formatting, styling
- `refactor`: Code restructuring
- `test`: Adding tests
- `chore`: Maintenance, config
- `perf`: Performance improvement

## Troubleshooting

### "ANTHROPIC_API_KEY not set"

**Solution**:
```bash
# Set the environment variable
export ANTHROPIC_API_KEY="your-key"

# Or add to ~/.bashrc
```

### "Not a Git repository"

**Solution**:
```bash
git init
git remote add origin https://github.com/your/repo.git
```

### "Push failed"

**Solutions**:
1. Check remote is configured: `git remote -v`
2. Set upstream: `git push -u origin main`
3. Check authentication (SSH keys or token)

### "Claude API error"

**Solutions**:
1. Check API key is valid
2. Verify internet connection
3. Check Claude API status
4. Falls back to basic commit message if Claude fails
