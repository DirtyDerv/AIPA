# Tools Directory

## BMF Work Logging Tools
- `bmf_immediate.py` - Command-line BMF work entry logger
- `test_gmail_connection.py` - Gmail workflow diagnostic tool
- `fix_gmail_workflow.py` - Gmail organization troubleshooter
- `github_upload.py` - Project upload script for GitHub

## Usage

### BMF Logging
```bash
python tools/bmf_immediate.py
```

### Gmail Testing
```bash
python tools/test_gmail_connection.py
python tools/fix_gmail_workflow.py
```

### Project Management
```bash
python tools/github_upload.py
```

## Configuration
Make sure to update credentials in `config/CREDENTIALS.md` before using these tools.
