STEP 2: Remote into the other Windows machine
--------------------------------------------------------------------
1. Press Win + R
2. Type: mstsc
3. Enter Computer: 192.168.0.14
4. Click Connect
5. Enter your username/password

--------------------------------------------------------------------
1. On the 192.168.0.14 machine, open File Explorer
2. Go to Desktop or Downloads folder
3. Paste the file (Ctrl+V)

--------------------------------------------------------------------
1. Right-click on restart_n8n_windows.ps1
2. Choose "Run with PowerShell"

   (If it says "execution policy", do this instead:)

   - Choose "Open with" > "PowerShell"
   - Or: Open PowerShell and type:
     powershell -ExecutionPolicy Bypass .\restart_n8n_windows.ps1

- Show you if it worked
